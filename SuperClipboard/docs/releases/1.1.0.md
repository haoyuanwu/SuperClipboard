SuperClipboard 1.1.0，适用于 macOS 14 及以上。

### 新增记事本

- 主页面和状态栏弹窗新增书本图标，点击切换记事本独立列表，再次点击返回历史。
- 历史记录右键选择“加入记事本”，保存文字、富文本、图片、文件和视频的独立副本。
- 记事本永久保留，不受历史条数上限和清空历史影响；保存完成后，删除源文件仍可预览、复制和播放受支持的视频。
- 支持搜索、排序、预览和复制，主页面支持类型筛选；相同内容不会重复存档。
- 默认保存在 `~/Library/Application Support/SuperClipboard/Notebook/`，设置中可更改目录并迁移已有内容。
- 存档和迁移在后台执行，包含原文件缺失、部分复制失败、目录冲突及索引损坏保护。

### 交互优化

- 卡片悬停轻微上浮，带柔和阴影和边缘高光；点击后轻压缩小并弹回。
- 详情页复制成功后显示绿色对勾，约 0.4 秒后自动关闭；失败时保留详情供重试。
- 状态栏弹窗每次打开默认显示历史记录，并清空上次搜索和复制提示。
- 弹窗内复制仍保持当前列表位置，下次打开再按共享排序排列。
- 动效适配系统“减少动态效果”。

### 下载与升级

| 文件 | 适用设备 |
| --- | --- |
| `SuperClipboard-1.1.0-arm64.dmg` | Apple Silicon / M 系列 Mac |
| `SuperClipboard-1.1.0-x86_64.dmg` | Intel Mac |

退出旧版应用，打开 DMG，将 SuperClipboard 拖入 Applications 并替换旧版。已有历史和设置会保留；需要永久保存的旧历史请手动右键加入记事本。

### 验证与说明

两个架构均进行 Release 构建、架构与签名完整性检查及 DMG 校验。存档测试覆盖文字、富文本、图片、文件、视频数据备份、源文件删除、历史清理、重新复制、重启恢复和目录迁移。Intel 版本尚未在实体 Intel Mac 上验证。

当前为临时签名，尚未经过 Developer ID 签名和 Apple 公证。macOS 首次打开可能要求在“系统设置 → 隐私与安全性”中按提示允许。视频播放能力取决于 macOS 支持的格式。加入记事本前已经丢失且无缓存的原文件无法补存；永久保留表示应用不会自动清理，手动删除存档或磁盘损坏仍会造成丢失。

附件提供功能介绍、更新记录和 SHA-256 校验文件。
