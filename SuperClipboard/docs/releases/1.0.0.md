SuperClipboard 首个公开版本，适用于 macOS 14 及以上。

### 功能

- 自动记录文字、图片、文件和视频文件，保留来源提供的富文本样式。
- 状态栏卡片列表、搜索、单击复制与右键管理。
- 来源 Logo 渐变卡片、图片预览、视频封面和详情播放。
- 复制计数、最近复制与复制次数排序，主页面和弹窗共用设置。
- 弹窗内复制不跳位置，下次打开时重新排序。
- 文件完整路径、访达定位、置顶和历史清理。
- 浅色、深色、跟随系统，开机启动默认开启且可以关闭。

### 下载

| 文件 | 适用设备 |
| --- | --- |
| `SuperClipboard-1.0.0-arm64.dmg` | Apple Silicon / M 系列 Mac |
| `SuperClipboard-1.0.0-x86_64.dmg` | Intel Mac |

打开 DMG 并拖入 Applications，随后从“应用程序”启动。首次运行会尝试开启登录项；如系统要求批准，请在“系统设置 → 通用 → 登录项”中允许。

### 说明

初版为临时签名，尚未经过 Developer ID 签名和 Apple 公证。首次打开如被系统拦截，确认来自本仓库后，在“系统设置 → 隐私与安全性”按系统提示允许打开。

两个架构均完成 Release 构建、Mach-O 架构、签名完整性及 DMG 校验；Intel 包尚未在实体 Intel Mac 上验证。文件移动或删除后历史路径可能失效；视频格式支持取决于 macOS；富文本样式以复制来源实际提供的内容为准。

附件提供功能介绍、更新记录和 SHA-256 校验文件。
